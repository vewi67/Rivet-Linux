# Rivet Linux: Attribution and Branding

Rivet is intended to be a reusable foundation. Fork it, learn from it, change it, and build your own distribution from it. Please do not erase the project's history or present the unmodified Rivet project as work you created from scratch.

## Source code and build configuration

Unless a file says otherwise, Rivet's original source code, build scripts, and configuration are licensed under the GNU General Public License, version 3 or (at your option) any later version (GPL-3.0-or-later).

When distributing covered source or modified versions, follow the GPL. In particular, preserve existing copyright and license notices. The GPL requires modified versions to carry prominent notices stating that they were modified, including a relevant date. Include the full license with distributions and provide corresponding source as required by the GPL.

A fork may have its own name, goals, maintainers, and original contributions. Clearly describe what you changed and keep upstream notices intact. A useful attribution line is:

> Based on Rivet Linux (https://github.com/vewi67/Tip-Linux). Modified by [your name or project]; changes: [brief summary].

This attribution example is a project-community request, not an extra condition added to the GPL.

## Branding and artwork

The GPL license for code does not automatically grant permission to use Rivet's project identity. The Rivet name, logo, and Chip mascot artwork are not granted under the code license unless a specific asset file says otherwise. Reusing or adapting those assets may require separate permission from their respective rights holders.

Forks should use their own name and visual identity unless permission to reuse Rivet branding has been granted. Do not imply that a fork is an official Rivet release or is endorsed by the Rivet project.

## Third-party components

Rivet is based on Debian and includes or may include third-party software and assets. Those components remain under their own licenses and notices. The repository's GPL license does not replace the licenses of bundled dependencies.

## Plain-language summary

- You may use, study, modify, and redistribute the GPL-covered Rivet code under the GPL's terms.
- If you distribute a modified version, keep required notices and clearly mark your modifications as the GPL requires.
- Give your fork its own identity; do not imply official Rivet affiliation.
- Check each asset and dependency's own license before redistributing it.
